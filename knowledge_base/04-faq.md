# 博扬（BOYANG）— 常见问题 FAQ

---

## 购买与选型

### Q1：单模和单纤有什么区别？我应该怎么选？
单模（Single Mode）指的是光纤类型，芯径细（9/125μm），传输距离远（10~80km+），跳线外皮通常为黄色。单纤（BiDi/Simplex）指的是用一根光纤同时收发两个方向的信号，需配对使用 A 端 + B 端。**选型建议：** 短距离（<550m）用多模 + 双纤，省成本；长距离用单模；光纤资源有限用单纤方案。

### Q2：光纤收发器和工业交换机有什么区别？
光纤收发器是 1光1电 的点对点光电转换设备，功能简单。工业交换机是多端口（如1光4电、2光8电）的交换设备，可连接多个终端，支持 VLAN、环网等管理功能。**如果只延长单条网线，用收发器；如果需要接入多个设备且有管理需求，用交换机。**

### Q3：博扬的产品支持 POE 供电吗？
工业交换机部分型号支持 POE（如 BY-GG104S 等），符合 IEEE 802.3af/at 标准，可为网络摄像头、无线 AP 等设备供电。光纤收发器不支持 POE。购买时请确认型号规格是否含 POE 功能。

### Q4：光模块可以混用不同品牌吗？
可以。博扬光模块兼容主流品牌交换机（思科、华为、H3C、锐捷等）。但需注意部分交换机默认限制第三方模块，需在 CLI 中关闭光模块认证。少数品牌（如某些思科 IOS 版本）可能严格锁定，建议先测试。

## 安装与连接

### Q5：收发器接上后 FX 灯不亮怎么办？
1. 检查收发器两端的 TX/RX 是否交叉对接（A 的 TX 接 B 的 RX，A 的 RX 接 B 的 TX）
2. 检查光纤跳线类型是否正确（单模模块需配黄色单模跳线，多模模块配橘色/水蓝色多模跳线）
3. 更换一根已知好的光纤跳线测试
4. 用光功率计测量对方发光是否到达本端
5. 两端模块规格是否一致（速率、波长、距离）
6. 如以上均正常，可能是模块或收发器本身故障，联系售后

### Q6：收发器能通但丢包严重怎么排查？
1. 测量收光功率是否在模块接收灵敏度范围内（一般 -8~-20 dBm 为安全值）
2. 光太强（> -3 dBm）需加光衰减器；光太弱（< -22 dBm）需检查光纤链路损耗
3. 检查光纤跳线是否脏污（用光纤清洁笔清洁端面）
4. 检查光纤是否有过度弯折（弯曲半径不小于 30mm）
5. 检查网线是否达标（建议超五类以上，最长 100 米）
6. 尝试更换电源适配器（劣质电源可能引入干扰）

### Q7：工业交换机怎么接环网？
1. 将两台 BY-GG208 交换机的两个光口分别互联，形成环形拓扑
2. 登录交换机 Web 管理页面，在环网设置中启用 ERPS 协议
3. 指定一台交换机为主节点（Master），其余为传输节点（Transit）
4. 主节点的副端口（Secondary Port）会被逻辑阻塞，防止环路，链路中断时自动切换（<50ms）
5. 不建议使用 STP 替代 ERPS（收敛太慢，30~50 秒）

### Q8：收发器和交换机端的光模块需要同一个品牌吗？
不需要。两端的模块只要速率、波长、距离、光纤类型一致即可，品牌可以不同。例如博扬的 1.25G 1310nm 10km 单模模块可以对接其他品牌的同规格模块。

## 故障处理

### Q9：电源灯不亮，设备不工作
1. 检查电源适配器是否插紧（收发器通常使用 5V 圆头适配器）
2. 用万用表测量适配器输出电压是否正常
3. 更换同规格电源适配器测试
4. 如更换电源仍不亮，可能设备主板故障，请联系售后

### Q10：光模块插入交换机后不识别
1. 确认交换机端口速率与模块匹配（千兆端口用千兆模块，万兆用万兆）
2. 检查交换机是否限制第三方模块（思科需执行 `no errdisable detect cause gbic-invalid` 和 `service unsupported-transceiver`）
3. 华为交换机需执行 `transceiver phony-alarm-disable`
4. 重新插拔模块，确保插到位（听到"咔"声）
5. 更换同型号模块测试，排除模块本身故障

### Q11：光端机电话口有杂音/不通
1. 检查电话线 RJ11 水晶头是否压接牢固
2. 测量光纤收光功率是否达标
3. 尝试更换电话机测试（排除话机故障）
4. 使用自环测试：将光端机光口用光纤自环（尾纤对折），电话口接电话机，摘机应能听到拨号音
5. 自环正常则故障在光纤链路，自环不正常则光端机本身故障

### Q12：POE 交换机灯亮但不给摄像头供电
1. 确认摄像头支持 POE（标准 802.3af/at，非 Passive POE）
2. 检查网线是否为 8 芯全通（4 芯线不支持 POE）
3. 网线距离是否超过 100 米
4. 交换机 POE 总功率是否已超载（查看交换机 POE 功率预算）
5. 尝试更换网口测试
6. 用 POE 测试仪测量端口输出电压

## 售后与退换

### Q13：买了用不上，可以退货吗？
签收 7 日内，商品完好、包装完好、配件齐全、不影响二次销售的情况下，支持无理由退货。光模块和收发器类产品如已上架使用（插拔痕迹明显），将无法通过退货验收。PLUS 会员免退货运费，普通用户需自付退货运费。

### Q14：保修需要提供什么凭证？
京东购买的凭订单号即可保修。线下渠道购买的需要提供发票或收据。保修期内非人为损坏免费维修，人为损坏或过保产品会先报价再维修。

### Q15：退货/维修要寄到哪里？
退货通过京东 APP 申请后系统自动生成上门取件地址（京东物流免费上门取件）。质保期内维修请先联系客服获取 RMA 单号和寄修地址，不要自行寄回以免无法录入工单。

### Q16：可以开增值税专用发票吗？
可以。在京东企业购频道下单，填写完整的开票资料（公司名称、税号、地址电话、开户行及账号），订单完成后开具增值税专用发票。个人用户只能在普通发票和电子发票中选择。

### Q17：发错货了怎么处理？
收货 24 小时内联系京东客服，提供开箱照片和商品实物照片。核实后京东安排补发正确商品并上门取回错发商品，运费由京东承担。

### Q18：质保期内设备故障，着急用怎么办？
联系博扬客服说明紧急情况，可申请"先发后修"服务：博扬先发出替换设备（需提供押金或签订借用协议），客户收到替换设备后安装使用，再将故障设备寄回维修。此服务需客服评估后确认。
